# ⚙️ الأنظمة

## 1. القتال
- 3 أسلحة (تبديل بزر).
- ضربة = 1 animation + 1 hitbox.
- كل سلاح له مدى وضرر مختلف.

## 2. الإنفنتوري
- 20 خانة (5×4).
- يخزن: أدوية، مفاتيح، شظايا، ذرات.

## 3. الألغاز
- صناديق (تُدفع).
- مفاتيح + أبواب.
- أزرار + منصات.
- جدران قابلة للتكسير.

## 4. NPCs
- 2 في كل قسم = 10 NPCs.
- كل NPC له مهمة.
- المهمة تعطي "ذرات" أو "أرواح".

## 5. الخريطة
- تتكشف شوي شوي (كل غرفة تزورها تظهر).
- خريطة 2D (top-down).
- علامات: غرف، متاجر، NPCs، أسرار.

## 6. الحفظ
- تلقائي (localStorage).
- يحفظ: HP، شظايا، ذرات، أرواح، قدرات، تقدم.
